# 最小 Web 界面验收

日期：2026-09-09，Node.js v26.8.1。此记录补充 CLI 验收，不改变模型接入的实验性边界。

## 自动验证

严格类型检查、编译与 25 项测试通过。其中新增两个 HTTP 集成测试覆盖：

- 访问口令、跨来源拒绝、创建故事、读取设定、环境检查与轮次记录；
- 保存设定形成独立提交，删除 Lore 后工作区干净且 Git 历史保留；
- 旧基准版本、非法路径、错误配置、脏工作区和故事软链接拒绝；
- 创建 / 切换分支，任务轮询、同故事并发拒绝、取消任务。

测试直接启动 HTTP 服务并执行编译后的 CLI，取消测试使用可控的长运行子进程。`npm test` 会先编译，避免使用过期 dist。

## 浏览器与真实服务

在本机浏览器从页面创建 `web-demo` 示例故事，通过网页执行了真实 DeepSeek + SiliconFlow RAG + Actor 生成：

- Turn：`3357cbb8-d1fd-44db-8fcc-8892f65e9f75`；
- Result Commit 前缀：`4d560b89`；
- 页面显示后台调用进度，完成后显示正文和已保存版本；
- 正文解释没有蓝色凭证时需要登记申请，登记不等于获准进入，并等待旅人决定；
- 通过网页编辑 Notebook，生成新 Commit `cec7bc74`，页面确认已提交。

最终服务重启后，网页独立检索再次返回白塔访问制度与来源版本，白塔访问制度重排分数约 0.999；运行记录可重新加载已完成正文。安装包在独立目录安装后，`cuet-web --help` 通过。

上述生成没有额外证明文学质量；模型也没有严格遵守约 200 字的篇幅要求。

浏览器使用 390 × 844 的手机视口检查了生成页面、长正文、设定编辑及运行记录。页面采用单列，根元素没有横向溢出，导航可横向滚动。手机视口下实际完成 Notebook 保存。另检查桌面布局。未在实体手机上测试键盘、系统浏览器或局域网连通性。

账号导入仍为本地 CLI 操作；Web 不接收服务商凭据。服务默认本机访问，局域网模式需显式启用。没有公网部署或多用户验收。
